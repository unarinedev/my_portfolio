# My Portfolio

## Description
A foundational personal portfolio website built entirely with pure, semantic HTML5. This project was developed as Task 1 for the CodeTribe Bootcamp, focusing strictly on proper document structure, accessibility, and element hierarchy before the introduction of CSS styling. It serves as a structural baseline for my digital presence as I continue to document my journey

## Pages Included
* **Home (`index.html`):** Features a main showcase section, a brief bio, and a footer containing quick links, social media references, and an embedded Google Map pointing to Ga-Mothiba, Polokwane.
* **About Me (`about.html`):** A dedicated page detailing my background.
* **Contact Me (`contact.html`):** A semantic HTML form designed to capture visitor inquiries.

## Technologies Used
* HTML5 (Pure Semantic Markup)

## What I Learned
Through this project, I reinforced my understanding of:
* Structuring web pages using native semantic tags (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* Embedding external media securely (video elements and Google Maps `<iframe>`).
* Creating accessible and logical navigation pathways across multiple static pages.
