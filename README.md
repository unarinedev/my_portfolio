# My Portfolio

## Description
A personal portfolio website built with pure semantic HTML5 (Task 1) and now fully styled with responsive CSS (Task 2) for the CodeTribe Bootcamp. 

## Pages Included
* **Home (`index.html`):** Features a main showcase section using CSS Grid layouts, a brief bio, and a responsive footer containing quick links, social media references, and an embedded Google Map pointing to Ga-Mothiba, Polokwane.
* **About Me (`about.html`):** A dedicated page detailing my background and technical stack.
* **Contact Me (`contact.html`):** A semantic HTML form styled with clean, modern input states designed to capture visitor inquiries.

## Technologies Used
* HTML5 (Pure Semantic Markup)
* CSS3 (Custom styling, Flexbox, and CSS Grid)

## What I Learned
Through this project, I reinforced my understanding of:
* Structuring web pages using native semantic tags (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* Implementing responsive web design using media queries (`@media`) to ensure seamless layouts across mobile, tablet, and desktop views.
* Using modern CSS architectures like Flexbox and CSS Grid for maintainable component layouts.
* Applying interaction design through CSS hover states, transitions, and smooth scrolling mechanisms.
* Embedding external media securely and responsively (video elements and Google Maps `<iframe>`).
